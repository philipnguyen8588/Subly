CÀI SUBTITLE TV LÊN TV SAMSUNG
==============================

1. CÀI TIZEN STUDIO (một lần trên máy tính)
- Tải: https://developer.tizen.org/development/tizen-studio/download → cài vào C:\tizen-studio.
- Package Manager: cài "Tizen SDK tools" (Main SDK), "Samsung Certificate Extension" và
  "TV Extensions" (Extension SDK).

2. BẬT DEVELOPER MODE TRÊN TV
- Xem IP máy tính: PowerShell → ipconfig → dòng "IPv4 Address".
- TV: vào Apps, bấm 1 2 3 4 5 (nút "123" để hiện số) → Developer mode = On,
  Host PC IP = IP máy tính → OK.
- Tắt hẳn TV rồi bật lại.
- Xem IP TV: Cài đặt → Chung → Mạng → Trạng thái mạng → Cài đặt IP.

3. KẾT NỐI MÁY TÍNH VỚI TV
    C:\tizen-studio\tools\sdb.exe connect <IP-TV>
    C:\tizen-studio\tools\sdb.exe devices
- Thấy TV trong danh sách là được.

4. TẠO CHỨNG CHỈ (mỗi TV mới phải làm)
- Tizen Studio → Tools → Certificate Manager → "+" → Samsung → TV.
- Đặt tên profile, ví dụ TV-NhaMinh.
- Author: dùng lại cái cũ, hoặc tạo mới (đăng nhập tài khoản Samsung).
- Distributor: chọn Public; DUID của TV đang kết nối tự hiện (thêm DUID TV khác nếu muốn
  dùng chung) → đăng nhập Samsung → Finish.

5. CÀI APP
    cd E:\Projects\VScodeProject\Subly\windows\tizen
    .\deploy.ps1 -Tv <IP-TV> -Profile TV-NhaMinh
- Thấy "install completed" là xong, app tự mở.
- Báo không cho chạy script: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
- "Cài lên TV thất bại": chứng chỉ chưa có DUID của TV → làm lại bước 4.
